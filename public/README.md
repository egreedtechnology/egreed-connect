# EGREED Identity SEO Sitemap

Domain:
https://id.egreedtech.org/

## Files

- `sitemap.xml` — XML sitemap containing the public, indexable EGREED Identity URLs.
- `robots.txt` — crawler directives and sitemap location.

## Public URLs included

1. https://id.egreedtech.org/
   EGREED Identity overview and primary landing page.

2. https://id.egreedtech.org/docs
   EGREED Identity developer documentation.

3. https://id.egreedtech.org/status
   EGREED Identity public service status.

## Intentionally excluded

The following are application, authentication, account, or administrative routes and should not be treated as SEO landing pages:

- https://id.egreedtech.org/auth
- https://id.egreedtech.org/account
- https://id.egreedtech.org/developer
- admin.id.egreedtech.org
- developer.id.egreedtech.org

Do not add URLs to `sitemap.xml` unless the URL is a real public page that returns HTTP 200 and is intended to be indexed.

## Search-engine submission

After deploying `sitemap.xml` and `robots.txt` on the domain, submit:

https://id.egreedtech.org/sitemap.xml

to Google Search Console and Bing Webmaster Tools.

## Important SEO note

A sitemap helps discovery and crawling. It does not guarantee indexing or rankings. Each public documentation URL should be added to the sitemap only after the corresponding page actually exists.
